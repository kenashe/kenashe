A Hacker News item making the rounds asks whether modern decor is straining people’s brains. I have not seen enough from that source alone to buy a strong neuroscience claim. “May be” is doing real work.

But the frame is useful.

A lot of AI-generated design has the same problem as the worst version of modern decor: it photographs well, looks expensive for three seconds, and then gives the human very little to hold onto. Smooth surfaces. Flat palettes. Repeating shapes. No hierarchy except whitespace. No signs of use. No friction, which somehow becomes its own kind of friction.

That is not just an interiors issue. It is a product issue, a model-output issue, and a workflow issue.

## The screenshot test is too weak

AI tools are very good at making something that passes the first glance test. A landing page mockup. A dashboard. A room render. A slide. A mobile screen. It looks finished because the model has learned the visual grammar of finished things.

That does not mean it is easy to live with.

The builder trap is mistaking polish for reduced cognitive load. These are different. A clean screen can still make the next action ambiguous. A minimal room can still feel dead. A generated report can still force the reader to reconstruct the logic because the structure is too smooth and generic.

This is where the decor claim matters, even if the evidence is not settled in the materials here. Humans do not process spaces, pages, and tools as static images. We scan, orient, predict, recover from mistakes, and use small irregularities as cues. Texture is not automatically clutter. Detail is not automatically noise.

AI systems tend to average out those cues unless we ask for them on purpose.

## Generative taste collapses toward “inoffensive”

Most commercial AI design defaults point toward inoffensive. Neutral tones. Rounded cards. Soft shadows. Symmetry. Calm gradients. The same apartment. The same SaaS dashboard. The same founder headshot lighting.

There is a reason for that. Models are trained on what gets published, pinned, liked, and reused. The dataset already over-represents surfaces that present well. Then the product layer adds safety, brand-friendliness, and template logic. The output becomes a compromise between “nice” and “unlikely to offend procurement.”

That can be useful for a first draft. It is dangerous as a final taste function.

The missing question is not “does this look modern?” It is “can a tired person use this without spending extra mental effort?” For a room, that might mean zones, contrast, material variation, and objects that imply what happens where. For software, it means visual hierarchy, plain labels, state clarity, and enough affordance that users do not have to infer everything from vibes.

For AI content, same deal. A beautiful paragraph can still be cognitively expensive if it hides the point. A concise answer can still be bad if it removes the landmarks.

## Treat comfort as an eval

I would like to see more AI design tools add evals that are not just aesthetic scoring. Ask what the user can infer in five seconds. Ask where the eye goes first. Ask what action is obvious. Ask what would confuse someone returning after a week away.

You can do this manually today. Generate three versions, then run a small critique pass with a different model and a human. Do not ask, “Which is best?” Ask, “Where will a person hesitate?” Ask, “What has been made so clean that it lost meaning?” Ask, “What detail should be restored?”

This is not an argument for maximalism. Bad clutter is still bad. It is an argument against treating sterile as the same thing as calm.

Practitioner’s take: if you use AI for interiors, product UI, decks, docs, or brand systems, add a “cognitive comfort” review before shipping. Print the screen. Squint at it. Hand it to someone with no context. Watch where they pause. Then use the model to add hierarchy, texture, affordances, and signposts. The catch most readers miss: the best fix may make the work look a little less generically impressive in a thumbnail, and much better in actual use.
